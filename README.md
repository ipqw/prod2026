# Luxury Shop — PROD 2026, фронтенд

Решение отборочного этапа олимпиады PROD 2026 (Т-Банк, Центральный университет, ФКН ВШЭ), трек
фронтенд: интернет-магазин на чистом JavaScript — без фреймворков, без сборки, без зависимостей в рантайме.

**Демо:** https://prod2026.ipqw.cc

## Что сделано

- Каталог: фильтры, поиск с подсказками, состояние фильтров и поиска в URL, скелетоны при загрузке.
- Карточка товара в модальном окне, корзина с подтверждением удаления, история покупок.
- Профиль с валидацией полей и сохранением настроек.
- Светлая и тёмная тема, вёрстка под мобильные и десктоп.
- Корзина, история, профиль и тема хранятся в `localStorage`.

## Стек

HTML, CSS (переменные, без препроцессоров), JavaScript (ES-модули). Каталог — `solution/data.json`.

## Тесты

33 e2e-сценария организаторов на Playwright (`tests/`), в том числе сравнение скриншотов на десктопе и
мобильном в обеих темах. CI прогоняет их на каждый коммит в `main` до сборки образа.

## Запуск

```
npm ci
npm start      # http://127.0.0.1:8080
npm test
```

## Деплой

`deploy/` — nginx-образ со статикой. GitHub Actions: тесты → образ в ghcr → тег в GitOps-репозиторий →
Flux выкатывает на собственный k3s-кластер, сертификат — cert-manager и Let's Encrypt.
